# @stagegate/admin

The internal StageGate administration application.

## Responsibilities

- Tenant management
- User management
- Subscription administration
- Feature flags
- Platform analytics
- System health
- Support operations
- Abuse management

## Security

This application is restricted to authorized
StageGate platform administrators.

Platform authorization must be enforced
by the backend API.

## Status

Workspace registered.

Implementation is scheduled for Phase 13.
