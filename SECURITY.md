# Security Policy

StageGate is a multi-tenant SaaS platform that
processes organization, speaker and proposal data.

Security and tenant isolation are core requirements.

## Reporting vulnerabilities

Do not disclose security vulnerabilities in
public issues or pull requests.

Report vulnerabilities privately to the
repository owner or authorized maintainers.

Include:

- Description of the vulnerability
- Affected component
- Reproduction steps
- Potential impact
- Suggested mitigation, if available

Do not include real customer data, credentials
or authentication tokens in vulnerability reports.

## Security requirements

- Least-privilege access
- Explicit tenant authorization
- Secure credential management
- Dependency security monitoring
- Input validation
- Audit logging
- Secure deployment practices

## Supported versions

StageGate is currently under active development.

Production support and vulnerability response
policies will be finalized before general availability.
